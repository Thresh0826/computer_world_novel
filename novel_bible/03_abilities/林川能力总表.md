# 林川能力总表

## 已确认调用

| 调用 | 已确认表现 | 限制或状态 |
| -- | -- | -- |
| `quit()` | 使林川脱离初始界蚀区域 | 原理与可重复性未知，不是退出世界 |
| `ls` | 读取环境、对象和自身状态 | 信息深度受对象与林川认知影响 |
| `fire()` | 生成火焰或点燃木柴 | 消耗精神 |
| `fire(2)` | 生成更大的短时火焰 | 比基础调用消耗更高 |
| `fire_ball()` | 生成并射出火球 | 连续使用造成明显精神负担 |
| `Translate()` | 翻译单句 | 只确认语言场景 |
| `Live_Translation()` | 连续理解并辅助表达当地语言 | 维持时持续占用精神 |
| `ps` | 查看目标正在运行的术式或核心内容 | 不保证看见内部实现 |
| `kill` | 中断银背狼当次运行的强化术式 | 不是删除，目标可重新施展 |
| `dash(1)`、`dash(2)`、`dash(3)` | 短时间提升自身速度；三倍冲刺已在第34章用于强攻黑袍青年 | 不消除伤势、惯性或体力负担；三倍调用时林川已感到腿骨、膝盖与精力的强烈负担 |
| `hardening()` | 强化自身表层防御 | 掌握度有限，持续消耗 |
| `strengthen()` | 短时增强自身力量 | 掌握度有限，高倍率会反噬身体 |
| `strengthen(3)`、`strengthen(4)` | 三倍强化用于石像战；四倍强化用于第34章强攻 | 高倍率会明显增加身体负担；四倍调用未能击破黑袍青年的防御 |
| `hardening(target, 5)` | 短暂强化凯恩受击部位，挡住瞬脊刺 | 单次危急用法，消耗极大；距离和复用边界未知 |
| `ip addr` | 读取通讯石本地编号 | 属于网络认知映射 |
| `ip route` | 读取魔讯塔默认路径和绑定目标路径 | 只确认洛恩当前实例 |
| `df -h` | 查看自身精神存储百分比；手持结晶核心时也可呈现其容量分区 | 属于认知映射，不证明对象是物理磁盘；尚未确认能否读取其他外部对象 |
| `dmesg | tail -n 30` | 读取最近的能力调用、精力变化、身体受击、目标结构损伤与意识中断记录 | 第28章首次调用；只确认能读取林川当时所见的最近状态日志，不等于全知回放 |
| `dmesg -T` | 将日志中的相对时间转换为林川可理解的具体时刻 | 第28章确认石像战后约于夜间七点意识中断、夜间十一点恢复；不得扩展为任意事件的时间查询 |
| `earth_sense()` | 感知与自身相连的岩层、碎石和裂缝；近距离可分辨厚薄与松紧，较远处只能判断有模糊物体存在 | 维持时精力快速下降；距离增加会显著降低精度；不能据此确认对象类别或身份，范围和定量消耗未知 |
| `spine_shot()` | 指定投射物与目标后瞬间发射；已用于木笔、碎石、细长结晶和钢针 | 威力受投射物与目标防御影响；连续实战会消耗精力，距离和常规上限仍未知 |
| `spine_shot(2)` | 第33章连续发射两根钢针配合破魔箭进攻黑袍青年 | 两次调用后继续冲刺近身，造成持续消耗；仅一针擦伤目标脸颊 |
| `spine_shot(3)` | 以钝头粗钢针击碎石像看门犬已开裂的手腕 | 消耗显著高于基础调用 |
| `spine_shot(4)` | 第34章同时发射三根钢针攻击黑袍青年 | 三根钢针均被黑洞吞没；当时林川未再计算剩余精力，调用后脑中更加模糊 |
| `spine_shot(5)` | 以钝头粗钢针扩大石像头部裂纹并打出缺口 | 高消耗；当时林川已处于重伤与低精力状态 |
| `spine_shot(8)` | 最后一击使石像头部结构崩解 | 调用时精力快速耗尽、意识中断；战后出现大量记忆缺失，二者因果尚未确认，不得常规化使用 |

## 当前精神存储

初始已用20%、可用80%。安装地感20%和瞬脊刺35%后，已用75%、可用25%。

## 未获得项目

岩甲15%、震步20%没有安装，林川不能直接调用。

## 第19—21章补充实测

* `spine_shot()`可反复命中长枪结晶人胸口同一位置，但普通碎石只能留下小坑，需要多次攻击才能形成细裂纹。
* `earth_sense()`首次近距离使用时，林川能从堵路碎石中判断斜上方最薄弱的位置。
* 第二次沿陡峭碎石坡向上延伸时，反馈受到距离和大量碎石干扰，只能感觉到两个模糊物体存在，不能确认其类别或身份。
* 两次感知都持续很短；林川明确感到刚恢复不多的精力被快速抽走。

## 第22—23章补充实测

* 林川手持结晶核心执行`ls`，只得到既有名称；执行`ps`没有反应，说明当时未显示运行中的术式。
* 对结晶核心执行`df -h`后，显示总容量100%、已使用35%、可用55%、系统占用10%。林川能继续查看已用部分中的战斗动作与残缺视野记录。
* 林川尝试吸收或安装结晶核心内容失败，精神存储没有变化；当前只确认手持时可查看。
* 林川购买细长钢针，计划作为`spine_shot()`投射物，但尚未在正文中实际调用，不能提前确认威力、精度或消耗。

## 第24—28章补充实测

* 细钢针能命中高速移动的赤尾猫，但初次实战偏离了林川矄准的脖颈；粗钢针能刺入变异巨鼠后腿。
* 高倍率瞬脊刺已确认三倍、五倍和八倍可调用，但负担急剧上升。八倍调用不得写成稳定常规能力。
* `ls`对中毒后的菲利克斯可呈现“毒素情况：严重”；该信息是当时特例，尚不证明`ls`能对任意毒素给出完整诊断。
* `dmesg`可在林川自身记忆缺失时提供最近调用和受损日志，但只有日志触发的零碎回忆，不是完整影像回放。

## 第29—30章补充实测

* 第29章中，`ls`读取治疗后的菲利克斯为“状态：中等”“毒素情况：微弱”；林川自检仍为“状态：虚弱”。状态恢复的原因只确认包含医馆治疗，不得据此补全菲利克斯复活规则。
* 第30章中，林川再次执行`dmesg | tail -n 30`，没有读到超出既有战斗、意识中断记录的新信息。该命令不能无限追溯或主动恢复缺失记忆。
* `ls`已将石像头部取得的核心识别为“石像看门犬核心”。
* 林川同时接触结晶核心与石像看门犬核心，以自身意识提供外部控制、输入和输出时，`ls`呈现“存储模块：已接入”“运算模块：已接入”“控制来源：外部”“临时结构：已建立”。两枚核心短暂完成一次简单运算，并在结晶核心可用区域留下临时信息。
* 该联动是一次性实验，不属于已经安装或可稳定调用的新术式；连接很快中断并使林川明显疲劳。可重复性、具体消耗、运算上限、数据修改风险及是否需要完整配套核心均未知。

## 第31—35章补充实测

* 第33章中，林川连续两次调用`spine_shot(2)`配合菲利克斯的破魔箭，再以`dash(2)`近身；攻击只在黑袍青年脸上留下轻伤，无法穿过其主要防御。
* 第34章中，`strengthen(4)`使全身肌肉与皮甲绑带明显绷紧；随后一次`spine_shot(4)`发射三根钢针，但被黑洞全部吞没。
* `dash(3)`首次出现于第34章。三倍速度显著增加控制难度，并使腿骨、膝盖和既有伤势承受强烈负担；不得直接当作无代价常规移动手段。
* 第33章中，`ls`将遭黑暗箭贯穿后的菲利克斯显示为“状态：死亡”；第35章送医后再次读取，显示“状态：中等”“恢复速度：极快”。该结果只确认菲利克斯个体特例，不代表`ls`可普遍读取所有对象的恢复属性。
