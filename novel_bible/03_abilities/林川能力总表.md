# 林川能力总表

当前已确认体系只有 Linux 与 Python。所有名称均是林川的认知映射，不代表诺维斯原生机制采用计算机实现。

## 已确认调用

| 调用 | 已确认表现 | 主要限制 |
| -- | -- | -- |
| `quit()` | 从黑红异常区域脱离 | 作用范围与可重复性未定；不是退出世界 |
| `ls` | 读取对象、环境与自身状态 | 信息深度受对象和认知限制 |
| `fire()` / `fire(2)` | 生成火焰，参数2会放大效果 | 放大同时增加精神消耗 |
| `fire_ball()` | 生成并射出火球 | 连续使用会造成明显精神负担 |
| `Translate()` | 翻译单句 | 只确认语言场景 |
| `Live_Translation()` | 连续理解并辅助表达本地语言 | 维持时持续消耗精神 |
| `ps` | 查看目标正在运行的术式或核心内可读结构 | 不能保证看见内部源码 |
| `kill` | 中断银背狼正在维持的强化术式 | 不是删除；目标可以重施 |
| `dash(1)` / `dash(2)` | 短时间提高自身移动速度 | 消耗精力，不消除伤势与惯性负担 |
| `hardening()` | 强化自身表层防御 | 掌握度低，持续与强度均有限 |
| `strengthen()` | 短时增强身体力量 | 掌握度低，高倍率会严重反噬身体 |
| `hardening(target, 5)` | 锁定凯恩后，短暂强化其背部并挡下瞬脊刺 | 单次危急用法；消耗极大，距离、成功率、复用上限未定 |
| `save(name)` | 保存一次观察或事件记录 | 占用精神存储，记录完整度未定 |
| `df -h` | 以百分比查看精神存储 | 第15章为已用37%、剩余63%；不是物理磁盘 |
| `ip addr` | 查看通讯石的本地编号和连接表现 | 属于认知映射 |
| `ip route` | 查看通过魔讯塔转接的路径 | 依赖区域网络 |
| `ping` | 测试与绑定通讯石目标的连通 | 会使目标通讯石产生呼叫反应 |
| `traceroute` | 查看连接经过的转接层级 | 只确认洛恩个例 |
| `ss` | 查看当前连接状态 | 可见范围未定 |

## 魔兽核心外接

| 核心 | 可读结构 | 已实际验证 |
| -- | -- | -- |
| 银背狼核心 | 硬化防御、躯体强壮 | 核心接触式调用；核心消失后两项能力可由林川直接调用 |
| 裂甲兽核心 | 岩甲、地感、震步、瞬脊刺 | 接触核心时使用 `earth_sense()`感知地面震动；以木笔为投射物试验 `spine_shot()` |

裂甲兽核心仍由林川随身携带，尚未 `import`，不得提前写成永久掌握四项能力。

## 函数封装边界

* 林川可以读取或修改明确暴露出来的外层参数。
* `spine_shot()`目前暴露投射物、方向、目标等参数；推进与加速的内部实现不可见。
* 西蒙的冷水流暴露方向、温度、流量等参数，但生成水、维持水体、降温等步骤被更深的方法封装。
* “温度可调”允许未来进行受控试验，不等于林川已经掌握水系治疗或能随意改写其他法术。
