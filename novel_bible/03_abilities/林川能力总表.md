# 林川能力总表

当前已知能力体系：Linux、Python。重构正文前三章确认：

| 调用 | 表现 | 限制/备注 |
| -- | -- | -- |
| `quit()` | 使林川从黑红异常区域脱离 | 作用范围、可重复性、消耗未定；不是世界退出或管理员权限 |
| `ls` | 读取并整理附近对象/现象名称，包括草地、石坡、溪流、野兽痕迹、界蚀 | 信息并非普通视觉文字；深度未定 |
| `fire()` | 点燃已有木柴，也能生成短暂火团 | 注意力被抽走一小截，机制未定 |
| `fire(2)` | 生成比 `fire()` 更大的短暂火团 | 消耗明显加重，具体参数规律未定 |
| `fire_ball()` | 生成并射出火球，命中狼并造成重伤 | 两次调用均造成明显精神/注意力消耗；精度、上限未定 |

## 未发布重构新增

| 调用 | 表现 | 限制/备注 |
| -- | -- | -- |
| `Translate()` | 将本地人的一句话转化为林川能理解的中文 | 只确认单句效果 |
| `Live_Translation()` | 连续理解本地语言，并辅助林川以对方语言表达 | 持续带来轻微精神负担；第4章末仍在运行 |
| `ps` | 读取银背狼正在运行的“躯体强壮”“硬化防御”及其强弱变化 | 当前只确认银背狼个例；范围、距离、对其他对象的效果未定 |
| `kill` | 中断银背狼正在运行的自身强化类魔法 | 不是永久删除；目标可重新施展。连续中断多个术式消耗明显，具体距离和成功条件未定 |
| `ls`（自身） | 显示林川生命、精力百分比 | 第5章受伤后显示生命70%、精力40%；指标机制和精度未定 |
| `ls`（魔兽核心） | 识别“银背狼核心”并显示“可读取” | 尚未实际读取，不得提前确认可获得何种信息或能力 |
| `dash(2)` | 直接作用于自身，使林川短时间以约原本两倍速度冲刺 | 会消耗精力；不会消除既有伤势，胸口受伤时奔跑仍会疼痛 |
| `dash(1)` | 以较低倍率加速赶路 | 提升较温和，消耗与完整参数规律未定 |
| `ps`（银背狼核心） | 在核心内看到“硬化防御”“躯体强壮” | 与 `ls`提供的信息层级不同；原理未定 |
| `hardening()`（核心外接） | 接触银背狼核心时使右手皮肤出现淡灰色硬化 | 松开核心后效果消失；尚未确认核心消失后的可用性 |
| `strengthen()`（核心外接） | 接触银背狼核心时使手臂产生力量增幅 | 松开核心后效果消失；尚未确认核心消失后的可用性 |
