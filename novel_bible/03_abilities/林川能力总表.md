# 林川能力总表

## 已确认调用

| 调用 | 已确认表现 | 限制或状态 |
| -- | -- | -- |
| `quit()` | 使林川脱离初始界蚀区域 | 原理与可重复性未知，不是退出世界 |
| `ls` | 读取环境、对象和自身状态 | 信息深度受对象与林川认知影响 |
| `fire()` | 生成火焰或点燃木柴 | 消耗精神 |
| `fire(2)` | 生成更大的短时火焰 | 比基础调用消耗更高 |
| `fire_ball()` | 生成并射出火球 | 连续使用造成明显精神负担 |
| `Translate()` | 翻译单句 | 只确认语言场景 |
| `Live_Translation()` | 连续理解并辅助表达当地语言 | 维持时持续占用精神 |
| `ps` | 查看目标正在运行的术式或核心内容 | 不保证看见内部实现 |
| `kill` | 中断银背狼当次运行的强化术式 | 不是删除，目标可重新施展 |
| `dash(1)`、`dash(2)` | 短时间提升自身速度 | 不消除伤势、惯性或体力负担 |
| `hardening()` | 强化自身表层防御 | 掌握度有限，持续消耗 |
| `strengthen()` | 短时增强自身力量 | 掌握度有限，高倍率会反噬身体 |
| `hardening(target, 5)` | 短暂强化凯恩受击部位，挡住瞬脊刺 | 单次危急用法，消耗极大；距离和复用边界未知 |
| `ip addr` | 读取通讯石本地编号 | 属于网络认知映射 |
| `ip route` | 读取魔讯塔默认路径和绑定目标路径 | 只确认洛恩当前实例 |
| `df -h` | 查看自身精神存储百分比；手持结晶核心时也可呈现其容量分区 | 属于认知映射，不证明对象是物理磁盘；尚未确认能否读取其他外部对象 |
| `earth_sense()` | 感知与自身相连的岩层、碎石和裂缝；近距离可分辨厚薄与松紧，较远处只能判断有模糊物体存在 | 维持时精力快速下降；距离增加会显著降低精度；不能据此确认对象类别或身份，范围和定量消耗未知 |
| `spine_shot()` | 指定投射物与目标后瞬间发射；已用于木笔、碎石和细长结晶 | 威力受投射物与目标防御影响；连续实战会消耗精力，距离和上限仍未知 |

## 当前精神存储

初始已用20%、可用80%。安装地感20%和瞬脊刺35%后，已用75%、可用25%。

## 未获得项目

岩甲15%、震步20%没有安装，林川不能直接调用。

## 第19—21章补充实测

* `spine_shot()`可反复命中长枪结晶人胸口同一位置，但普通碎石只能留下小坑，需要多次攻击才能形成细裂纹。
* `earth_sense()`首次近距离使用时，林川能从堵路碎石中判断斜上方最薄弱的位置。
* 第二次沿陡峭碎石坡向上延伸时，反馈受到距离和大量碎石干扰，只能感觉到两个模糊物体存在，不能确认其类别或身份。
* 两次感知都持续很短；林川明确感到刚恢复不多的精力被快速抽走。

## 第22—23章补充实测

* 林川手持结晶核心执行`ls`，只得到既有名称；执行`ps`没有反应，说明当时未显示运行中的术式。
* 对结晶核心执行`df -h`后，显示总容量100%、已使用35%、可用55%、系统占用10%。林川能继续查看已用部分中的战斗动作与残缺视野记录。
* 林川尝试吸收或安装结晶核心内容失败，精神存储没有变化；当前只确认手持时可查看。
* 林川购买细长钢针，计划作为`spine_shot()`投射物，但尚未在正文中实际调用，不能提前确认威力、精度或消耗。
