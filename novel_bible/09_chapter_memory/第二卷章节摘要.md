# 第二卷章节摘要

## 第40章《归生石》

* 诺亚向林川坦白“归生石”是家族称呼：其祖父曾随北大陆猎团参与击杀至少六阶的“冬眠兽”，在其心脏附近获得一枚指甲大的浅红半透明生命结晶。
* 归生石经祖父、父亲传给诺亚；他一岁多误吞后高烧，原有微弱魔感完全消失，治疗魔力会被部分吸收，遂无法成为法师。
* 诺亚确认三次死亡恢复：14岁溺水约两小时后恢复；19岁被魔兽撕开胸口后十余分钟恢复；洛恩影箭事件为第三次。恢复后会极度饥饿，且速度似乎变快。
* 归生石仍在体内但位置不明；不是绝对不死，头颅毁坏、大面积焚烧或组织不足时的结果未知且被认为危险。
* 林川以 `ls/ps` 观察到诺亚生命循环异常、魔力储备极低与低活性后台状态；他提出“认知影响可见信息”的个人观察，未构成机制结论。
* 两人建立秘密互不强逼的平衡；六日后抵达澜河城，第二卷的城市活动尚未开始。
