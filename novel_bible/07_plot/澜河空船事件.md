# 澜河空船事件

## 资料层级

本文件记录作者已经确认的后续剧情框架。除已进入第37章正文的澜河城外观外，空船、影港、界蚀鲨、女角色A、护航队长及Java式修复均属于后续规划，尚未成为正文事实。写作时可以调整章节分配、人物姓名、具体招式和伤亡，但不得改变已确认的核心因果。

## 事件定位

* 所属卷：第二卷《洛恩河》。澜河是洛恩河支流，本事件不另开新卷。
* 主要功能：展开澜河城航运体系；以空船谜团重新连接界蚀与林川寻找地球的主线；让林川从Python式封装调用开始接触Java式完整对象组织；安排三次目标不同的战斗；建立林川、菲利克斯与女角色A的合作关系。
* 黑环长刺势力在本事件中暂时退场，不参与空船、影港与界蚀鲨事件。

## 航道前史

### 原航道

澜河主航线由多个大型引航节点维持，基础拓扑为：

`A → B → C → 分叉 → D1（南港）/ D2（北港）`

B位于河面最宽、水势最复杂的河段。三个月前，一处巨大界蚀降临并覆盖B附近水域。法师无法在不长期封航的情况下直接处理界蚀，澜河方面决定停用B，在界蚀外围建设新的绕行节点B2：

`A → B2 → C → D1 / D2`

旧引航石B并未被及时拆除，新的B2已经投入运行，因而新旧两座大型引航石同时存在。旧B仍在界蚀内部或边缘持续与航道发生微弱共鸣，并成为隐藏旧航道和影港异常得以维持的重要锚点。

### 测试航道与法师死亡

负责改道的法师为避免真实商船承担试错风险，在B2内部建立了一套仅供无人测试船使用的临时航道：

`B2 → 测试C' → 测试D1'/D2' → 测试港口`

施工期间，界蚀中出现的巨大水生怪物袭击法师与施工设施，法师死亡。后续人员修复了B2通向真实C的主路线，却不知道深层的测试路线仍被保留，也没有完成以下收尾：

* 注销测试C'与测试港口；
* 删除主路线故障后的测试回退规则；
* 关闭无人测试船的自动回收功能；
* 为活人建立进出测试空间的完整通行关系。

界蚀、法师死亡时的魔法反噬与未注销的测试结构共同作用，使原本只用于测试的港口获得了异常空间实体，即“影港”。

### 首都法师与五日拆除令

新旧引航石并存后，航道不断出现难以稳定复现的异常。第二艘空船返回及相关报告最终引来一名首都法师进行简略检查。

这名法师只检查了新旧引航石的外部运行和界蚀共鸣，没有深入追查隐藏备用路线。他判断若要由首都派出的高阶队伍正式解决界蚀，必须先拆除仍在提供坐标和共鸣的旧引航石B。

由于他态度高傲，不愿亲自处理拆石、断开旧线路和搬运材料等“杂活”，只向澜河本地人员下令：五天内完成旧引航石拆除。五日后，首都将再派三至四名法师前来处理高难度界蚀。

该命令形成空船事件的现实倒计时。对官方而言，拆除旧B是处理界蚀的前置工作；对被困者而言，旧B又是影港仍然存在的空间锚点。若在救人和迁移航道之前直接拆除，影港可能关闭、坍缩或永久失去定位。

## 空船产生机制

### 误入

正常情况下，船只经B2驶向真实C。只有旧B、B2、界蚀鲨及界蚀空间发生特定共鸣时，未注销的备用结构才会覆盖正常航道，将少数船只送入影港。因此此前只有零星船只失踪，不会造成所有商船同时消失。

### 假抵达

影港会按照测试港口的结构呈现灯塔、码头、接引人员、钟声和港口建筑。船员经历袭击或异常航行后，会误以为已经抵达真实港口，继而主动下船。

### 为什么船能回来，人不能

影港里的船不是重新驶出旧航道，而是被无人测试系统定时回收。自动回收只登记：

* 船体；
* 引航石；
* 已绑定货物。

测试结构没有建立乘员关系。活人即使重新登上后来抵达的船，也不会因此成为返航对象。回收开始时，船体和登记货物会逐渐脱离影港，活人则被空间排斥并留在港内。进入影港的回退通道在抵达后已经关闭，手动驾驶也无法原路返回。

林川认知中的关键问题不是一个简单参数错误，而是返航对象只包含`Vessel`，没有把船员和乘客组织进同一个完整运输对象。

### 时间流速

影港与现实的时间流速不一致。现实中从最早事故到林川进入已经过去数月，最早进入影港的人主观上却只经历了数小时；现实里相隔多日或数月抵达的船，在影港中的到达间隔可能只有片刻。

这一规则解释了早期幸存者尚未因长期缺水、饥饿和疾病全部死亡，也会制造认知冲击：幸存者可能认为事故刚发生不久，无法理解外界为何已经过去数月。具体换算比例不固定，不写成可稳定利用的时间加速能力。

## 主线流程

### 第一阶段：澜河落脚与第二艘空船

1. 林川与菲利克斯在澜河城落脚，在港口生活、观察或接取短期工作，由此熟悉河道、码头、引航石和航运规则。
2. 第二艘无人空船返回澜河港。船体与货物仍在，船员全部失踪。因为已有前例，船行开始给正常货船增派一至两名护航战职者；首都方面也派人进行一次简略检查，并下达五日内拆除旧引航石的命令。
3. 林川暂时观望，并因事件可能涉及界蚀而产生兴趣。
4. 林川、菲利克斯通过尚未确定的自然契机结识女角色A。她掌握一部分旧航道资料，并有调查空船的私人动机，但真实身份、与死去法师的关系及隐瞒内容尚待确定。

### 第二阶段：第一次秘密登船

5. 三人不经过船务或官方授权，秘密登上一艘必经B2的货船，准备在真实航行状态下观察引航石。
6. 第一次航行没有触发异常，船只正常经B2连接真实C。林川却借此完整解析船载引航石在实际航行中的结构，看见静止检查时无法呈现的对象关系：船只、新旧引航石、真实C、主路线、隐藏结构与自动恢复关系。
7. 林川此时仍不能修改整套结构，但从引航石内部找到一个可以被主动触发、放大并向大型节点传递特定信息的结构。这是Java式认知的第一次明确铺垫，也是第二次登船能够主动实验的基础，不等于已经掌握Java式术法。
8. 菲利克斯认为一次正常航行已经说明三人可能想多了，并指出偷渡、林川伤势和女角色A隐瞒信息带来的实际风险。林川与女角色A则认为“没有触发”本身证明异常需要额外条件。
9. 林川与女角色A根据第一次解析结果设计第二次实验：主动触发引航石内部结构，并尝试把林川自身的界蚀气息作为信息放大后传向新旧节点。第二次行动因此不是单纯重复碰运气。

### 第三阶段：第二次登船与首次界蚀鲨战

10. 林川与女角色A决定再次登船，主动验证第一次解析出的引航结构。菲利克斯认为他们在没有充分证据时继续冒险，第一次行动留下的意见冲突在此兑现；他最终仍以保护同伴为由同行。
11. 他们选择船员较少的夜间返航货船，避免主动让大量普通乘客承担风险。船上按新规配有一至两名护航战职者。
12. 林川主动触发第一次解析出的引航结构，并以其放大自己身上的界蚀气息及地球痕迹。被放大的气息经船载引航石传向新旧大型节点，唤起界蚀鲨对“地球人气息”的记忆，从而主动锁定并袭击船只。其记忆来源、过去是否在地球接触过人类以及如何穿过界蚀，均不在此时直接解释。
13. 界蚀鲨攻击船只与引航结构。林川、菲利克斯、女角色A及护航人员共同迎战，目标是活下来并保护船体，不在此战彻底杀死怪物。
14. 界蚀鲨的袭击使旧B、B2与界蚀空间同时发生剧烈共鸣，隐藏旧航道重新覆盖现实河道，异常空间被开启或扩大，整艘船由此坠入影港。影港并非此刻才被创造；此次攻击只是再次打开已经存在的异常结构。

### 第四阶段：假港口与护航队长战

15. 众人看见足以以假乱真的正常港口。船体受损、船员受伤，护航队长基于职责命令全员下船接受治疗。
16. 林川以`ls`发现港口名称缺失、状态接近测试结构，且船只自动回收倒计时正在运行。女角色A也从建筑或术式上认出旧测试港口的痕迹。二人阻止船员下船。
17. 护航队长发现林川三人是偷渡者，又知道女角色A接触过引航结构，自然怀疑异常由三人造成。林川无法在倒计时结束前证明影港性质，双方爆发战斗。
18. 主要护航队长暂定为擅长狭窄甲板战的二阶高位或二阶巅峰战士；另一名护航者可在界蚀鲨袭击中受伤，以免同时堆叠两名强敌。具体阶位、武器和姓名尚待正文前确认。
19. 林川的目标不是杀死队长，而是守住跳板、阻止船员离船并拖过自动回收倒计时。他利用`ls`看到的倒计时、船身启动时机、系船结构和已有能力，在信息层面取得胜利。
20. 队长可在船身突然返航时跌入码头，林川与菲利克斯随后用绳索或箭将其救回，证明阻止下船不是为了加害船员。港口景象开始重复、透明或错位，真正的失踪者随之出现。

### 第五阶段：影港真相

21. 众人发现此前失踪的部分船员仍活在影港。外界虽然已经过去数月，他们主观上却只经历了数小时。幸存者已经多次尝试搭乘后来抵达的船只离开，但自动回收只带走船体与登记货物，活人始终被排斥在影港。
22. 林川逐步确认影港是死去法师没有完成注销的无人测试环境；真实主路线已经修复，深层备用路线、测试港口和自动恢复规则却仍然运行。
23. 女角色A的真实身份、私人目标及此前隐瞒的信息在这一阶段揭开，但不得在确定前擅自写成死去法师的女儿、学生或恋人。
24. 护航队长在确认真相后转为有限合作：负责约束船员、修补船只、组织幸存者和最终战防线，但不会立即变成对林川言听计从的追随者。

### 第六阶段：Java式修复与最终战

25. Python式封装调用只能让林川查看或调整引航强度、目标等公开参数，无法补上缺失的对象关系。林川必须开始理解并组织完整的航道对象。Java式结构虽然能减少多次Python封装调用造成的重复魔耗，但理解和维持复杂关系会产生更高的思考与精神控制负担。
26. 修复方式不是直接改写正在运行的旧结构，而是：建立新的临时安全路线；创建包含船体、船员、乘客与幸存者的完整运输对象；完成小范围测试；将目标迁移到新路线；最后关闭并注销旧测试路线及自动恢复规则。随着精力降低，林川认知中的Java结构会逐渐模糊，先丢失具体代码和关系提示，严重时只剩无法直接理解的本地魔法图案，使修复过程随时可能退回诺维斯法师的原始认知层。
27. 重新启动或校准B2会再次释放强烈信号，界蚀鲨必然返回。最终战必须与修复同时发生，而不是修完程序后再单独刷怪。
28. 女角色A负责稳定航道术式，护航队长组织船员与防御，菲利克斯进行远程压制，林川在完成结构修复的同时参与决定性攻击。
29. 界蚀鲨的最终击杀应结合船只、引航石、狭窄水道、锁链或重型投射物等澜河环境，不得只靠林川临时放大既有技能正面秒杀。
30. 幸存者经新路线返回现实，旧测试结构被关闭，旧引航石随后才能在五日命令到期前安全拆除，空船事件结束。林川由此完成Java式认知的正式入门，但掌握范围仅限此次依托既有航道结构完成的对象组织与迁移，不等于能够随意编写任何大型术式。

## 战斗节奏

1. 首次界蚀鲨战：遭遇与求生，结果是被逼入影港，不分彻底胜负。
2. 护航队长战：信息差和职责冲突，林川以倒计时与船体运动取胜，不杀对方。
3. 最终界蚀鲨战：修复与战斗并行，多角色分工，林川完成技术与战斗双重决胜。

三场战斗的对手、目标、场地状态和胜负条件均不同，避免重复疲劳。

* 黑环长刺势力暂时搁置，不在本事件中追加追兵、实验品或幕后操控。
* 影港、界蚀鲨的记忆和航道真相均按线索逐步揭示，不得由某个角色一次性完整讲解。
