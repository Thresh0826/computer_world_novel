# 人物时间线

## 林川

地球办公室异常 → 初至界蚀 → 荒野求生 → 接触本地人 → 参与银背狼战 → 随阿尔文商队进入贝恩 → 登记一阶战士 → 加入凯恩小队 → 裂甲兽战救下凯恩 → 进入洛恩 → 获得核心与通讯石 → 接触塞维尔 → 安装地感与瞬脊刺 → 接受南郊矿洞任务并训练基础剑术 → 因界蚀爆炸坠入隐藏下层 → 独战长枪结晶人 → 与菲利克斯互救并击杀目标 → 取得结晶核心、实测地感并发出求救箭 → 在凯恩、西蒙协助下脱困并结算任务 → 读取结晶核心容量、动作和残缺影像 → 休养一周并发现未知标志 → 以`ls`发现菲利克斯“状态：优秀” → 与正式入队的菲利克斯接取采石场联合委托并补充装备。

## 凯恩小队

贝恩接受裂甲兽任务 → 途中发现岩角鹿异常迁徙 → 遭裂甲兽夜袭 → 米娅骨折、凯恩和巴洛受伤 → 击杀裂甲兽 → 进入洛恩治疗和结算 → 凯恩向林川表达感谢并建立通讯联系 → 凯恩带西蒙、林川执行南郊矿洞任务 → 界蚀爆炸后林川坠落，凯恩与西蒙留在上层组织救援 → 二人配合完成脱困，凯恩胸伤恶化 → 菲利克斯加入固定队 → 西蒙临时调往贝恩。

## 菲利克斯

与原小队接受南郊矿洞地下魔兽任务 → 界蚀爆炸后坠入隐藏下层并与队友失散 → 首次遭遇长枪结晶人并自称靠装死脱身 → 在林川濒死时射箭救援 → 与林川合作击杀长枪结晶人 → 正式自报姓名与新晋二阶身份 → 与林川寻找出口并射出求救箭 → 随凯恩、西蒙脱困 → 因失踪被原队按死亡挂牌，归来后遭拒绝 → 加入凯恩固定队 → 与林川接取采石场联合委托。

## 塞维尔

贝恩图书馆察觉林川异常 → 派人观察 → 在洛恩图书馆与林川正式交谈 → 给出地址卡，等待林川自愿联系。
