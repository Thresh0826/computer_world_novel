# 第三十二章 黑色核心

林川和诺亚都没有拒绝魔讯院的安排。

准确来说，也没什么拒绝的理由。

有人可能正在查他们是谁。

甚至可能准备灭口。

这种时候坚持“我自己住就行”，不叫独立自主，叫主动降低生存率。

诺亚本来就是来洛恩找活干的。

他是北方人。

家不在维尔兰东部，平时基本都住在洛恩，只有几个重要节日才会回去。

“我本来有住处。”

诺亚说道。

“不过既然他们免费给房间。”

“那就住。”

林川点头。

“很合理。”

白送的安全屋。

没有拒绝的必要。

魔讯院给他们安排的地方位于洛恩北区。

不是监牢。

也不是什么秘密据点。

就是一家正常营业的旅店。

只是整整第三层暂时不接普通客人。

楼梯口、后门和街对面都安排了职业者。

林川第一天进去的时候大概看了一遍。

三名三阶。

四名二阶。

轮班。

另外还有一个四阶法师长期坐镇。

这个配置已经明显超过普通旅店保安。

诺亚看完以后却问了一句。

“就一个四阶？”

负责把他们送来的魔讯院工作人员看了他一眼。

“你觉得应该几个？”

“我不知道。”

诺亚说道，“既然有人可能来杀我们……”

“你们是可能被灭口。”

工作人员纠正。

“不是王室成员。”

诺亚：“……”

对方继续说道：

“四阶职业者在洛恩也不是旅店门卫。”

“能长期安排一名四阶法师坐镇，已经是监察部批准的临时保护规格。”

“如果确认对方派出五阶以上人员。”

“会再调整。”

林川觉得很合理。

社会资源永远有限。

总不能因为两个一阶职业者发现一台非法监听设备，就调十个高阶强者站门口二十四小时轮班。

真这么安排。

林川反而要怀疑自己是不是漏看了什么，实际上已经成了国宝。

入住以后。

事情意外地平静。

第一天。

什么都没发生。

第二天。

还是没有。

甚至连一个可疑的人都没出现。

林川偶尔会用通讯石看一下连接。

`ss`

正常。

`ip route`

正常。

没有奇怪通讯。

也没有什么神秘编号试图找上门。

生活平静得像采石场那一堆事情从来没发生过。

诺亚恢复得尤其快。

第一天走路还会明显偏左。

第二天下午已经能在房间里拉弓。

当然。

没真射。

旅店老板大概不会喜欢自己的墙上突然多一个箭孔。

林川还是忍不住重新看了一次。

`ls 诺亚`

状态：恢复中。

伤口愈合：良好。

腐蚀残留：接近无。

恢复速度：异常偏高。

异常。

这两个字终于出现了。

林川盯了一会儿。

进一步解析。

没有结果。

诺亚注意到他又看自己。

“你这两天老盯着我腿干什么？”

“恢复太快。”

“治疗师也这么说。”

诺亚自己反而没太在意。

“我从小伤就好得快。”

林川抬头。

“从小？”

“嗯。”

“骨折呢？”

“没断过。”

“重伤？”

诺亚想了一会儿。

“最严重就是这次。”

“以前最多被箭划过。”

林川没有继续。

现在就算怀疑，也验证不了。

总不能跟他说：

要不我现在捅你一下，看看恢复速度。

这种实验伦理多少有点问题。

所以这两天。

林川真正花时间最多的。

还是那颗东西。

黑色小核心。

准确来说。

它到底是不是核心。

现在都不好说。

东西只有拇指指节大小。

近乎正圆。

表面黑得很干净。

没有魔兽核心常见的金色纹路。

没有明显魔力波动。

甚至连材质都看不出来。

第一次：

`ls`

全是问号。

第二次。

还是。

这两天林川精神状态恢复以后，又试了一遍。

名称：？？？

类型：？？？

状态：？？？

来源：？？？

功能：？？？

很好。

非常稳定。

稳定地什么都不知道。

林川没有贸然继续往里面灌精神力。

上次八倍`spine_shot`的后遗症还没完全消。

这两天虽然精神恢复到正常水平，可只要连续使用能力时间稍长，太阳穴还是会轻微发胀。

至少短期内。

不能再玩一次八倍。

他改成更熟悉的办法。

既然`ls`看不懂。

那换命令。

先：

`file unknown_core`

有反应。

林川精神一振。

调用。

反馈非常慢。

几秒以后：

**结构化对象。**

**格式未知。**

“……”

比问号强。

至少确定它不是一块普通石头。

继续。

`strings unknown_core`

这一次。

没有任何有意义结果。

没有名称。

没有术式。

没有可读信息。

再：

`du unknown_core`

失败。

无法确认容量。

林川摸着下巴。

如果是普通魔兽核心。

他触碰以后应该能看到固有术式。

像裂甲兽那样。

`earth_sense()`

`spine_shot()`

然后：

`from core import ...`

可这东西里面什么函数都没有。

那么能不能直接吸收？

这是他最开始的想法。

银脊狼核心整颗消失以后，能力留下。

裂甲兽核心则可以选择性导入。

既然这个黑色小东西是从魔像核心内部挖出来的。

有没有可能也能：

`import`

林川想了想。

先试：

`import unknown_core`

有反应。

但没有执行。

反馈：

**对象不可作为标准术式模块导入。**

林川没有失望。

反而开始觉得有意思。

“不是模块。”

那是什么？

他又试：

`from unknown_core import *`

失败。

没有可导入术式。

吸收路线暂时堵死。

林川靠在椅子上。

把东西放在桌面。

盯了几分钟。

模块不是。

普通核心也不像。

有结构。

但格式未知。

这种感觉越来越像什么？

一个电脑插上新设备。

系统知道：

东西接进来了。

但不知道：

这到底是什么文件系统。

林川忽然坐直。

“等等。”

如果它不是模块。

有没有可能是……

存储？

这个念头刚出来。

他自己都觉得有点离谱。

但试一下又不要钱。

准确来说。

要一点精神力。

他拿起黑色小核心。

尝试：

`lsblk`

一瞬间。

第一次出现了真正不同的反馈。

林川眼神立刻变了。

意识里。

除了自己熟悉的精神存储之外。

居然真的多出一个独立对象。

没有名称。

没有已知容量。

没有格式。

但它确实被列成了一个：

**外部块状对象。**

林川盯着结果。

半天没说话。

“还真是盘？”

当然。

只是他的能力把它理解成“块设备”。

不代表这东西真是某块异世界硬盘。

但这已经足够证明：

它和普通魔兽核心完全不同。

林川继续尝试。

`mount unknown_core`

这一次。

反馈不是失败。

也没有成功。

而是一句很奇怪的信息：

**目标可挂载。**

**无法识别内部结构。**

林川整个人都安静了。

可挂载。

只是看不懂格式。

这一下性质完全变了。

以前所有魔兽核心。

本质都是：

储存魔力。

维持术式。

提供技能。

这颗东西却没有任何术式。

反而可以被自己的能力识别成某种外部存储结构。

那里面装的是什么？

记录？

魔法？

控制程序？

还是构装体的某种核心信息？

林川第一反应就是想继续拆。

但刚调动精神力。

太阳穴就跳了一下。

身体给出的提醒非常明确。

别作死。

他停了。

这两天本来就是恢复。

不是找个更高级的东西把自己再次弄晕。

而且魔讯院的人随时可能找他们。

真把自己折腾昏迷，多少有点不给保护人员面子。

林川把黑色核心重新包好。

放回贴身口袋。

没有吸收。

至少现在不行。

不过这两天已经不是毫无收获。

他至少知道三件事。

第一。

这东西不是普通魔兽核心。

第二。

它内部确实存在某种结构。

第三。

自己的能力把它识别成了一个可以“挂载”的外部对象。

至于怎么读。

以后再研究。

天色逐渐暗下来。

诺亚坐在窗边，正在重新缠腿上的绷带。

“晚上吃什么？”

“肉。”

林川回答得很快。

“又吃肉？”

“我需要恢复。”

“我也需要。”

两个人对视一眼。

很好。

意见统一。

门外走廊上。

三阶战士的脚步声刚刚经过。

楼下还有四阶法师。

街对面也有人盯着旅店入口。

这两天一直很安全。

安全到诺亚甚至已经开始觉得魔讯院可能有点小题大做。

林川倒没这么想。

没有事情发生。

只能证明对方暂时没动。

不代表不会动。

他下意识摸了一下装着黑色核心的口袋。

又看向窗外已经亮起的魔法灯。

不知道为什么。

这两天越平静。

他反而越觉得。

这份平静。

可能不会持续太久。

【第三十二章 完】
