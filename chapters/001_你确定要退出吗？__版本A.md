# 第一章 你确定要退出吗？

晚上十一点四十七分。

机房里只剩下风扇转动的声音。

一排排服务器亮着绿色指示灯，冷气从架空地板下面往上灌，吹得林川后颈有些发凉。

他盯着电脑屏幕，已经足足五分钟没有动过鼠标。

屏幕上只有一行字。

`Connection reset by peer.`

“又断？”

林川皱了皱眉。

今天这台机器已经折腾他快三个小时了。

下午还只是偶发掉线，到了晚上，SSH连接几乎每隔几分钟就会莫名其妙断开。网络没丢包，交换机端口也正常，系统日志里更找不到什么像样的报错。

典型的那种最让人烦躁的问题。

它不是彻底坏掉。

它只是不断告诉你：

我有问题。

至于什么问题？

你猜。

林川端起旁边已经凉透的咖啡喝了一口，苦得皱了下眉。

他把杯子放回桌上，再次连接服务器。

密码输入。

回车。

黑色终端窗口闪了一下。

连接成功。

林川下意识敲了几个常用命令。

没有异常。

CPU正常。

内存正常。

磁盘正常。

网卡也正常。

仿佛刚才那几次断连根本没有发生过。

“装死是吧。”

他低声嘟囔了一句。

时间已经快到零点。

如果不是明天一早有人要用这台机器，他早就关电脑回去了。

林川靠在椅背上，揉了揉发酸的眼睛。

二十四岁，工作第二年。

大学专业学得杂，C、Java、Python都碰过，工作以后真正用得最多的反倒是Linux和Python。

要说多厉害，谈不上。

但服务器有什么常见毛病，该查哪里，该怎么看，他基本都知道。

所以现在这个问题才显得更加古怪。

没有日志。

没有网络异常。

没有负载异常。

机器就是毫无征兆地断开连接。

林川想了想，又开了一个窗口。

就在这个时候。

原来的终端突然闪了一下。

他愣住了。

窗口里的内容变了。

刚才还正常显示着服务器主机名的提示符，不知什么时候消失了。

取而代之的是：

`[unknown@unknown /]$`

林川坐直了一些。

“嗯？”

他第一反应是终端显示出了问题。

可他很快发现不对。

公司里的服务器命名虽然混乱得像是不同年代的文明遗迹，但至少不可能有一台机器叫“unknown”。

更不可能用户名也是unknown。

他敲下：

`pwd`

回车。

屏幕返回：

`/`

林川眉头皱得更紧。

他又输入：

`whoami`

几乎没有延迟。

结果出现。

`guest`

林川盯着那个单词。

“guest？”

他没有创建过这个用户。

更何况，刚才明明是用root权限登录的。

他伸手拿过手机，看了一眼微信群。

没人发消息。

也不像是同事远程搞什么恶作剧。

林川重新切回终端。

输入：

`hostname`

回车。

没有结果。

只有一个空行。

他又试了一次。

依然如此。

这一下，他反而来了点兴趣。

困意消失了不少。

服务器坏得莫名其妙不可怕。

可怕的是它开始表现出一种不属于服务器故障的创造力。

林川输入：

`ls`

光标闪动了一下。

没有列出任何目录。

整个根目录像是空的。

“开什么玩笑……”

Linux根目录怎么可能什么都没有？

他想输入`ls -al`，手指刚落到键盘上，终端却自己出现了一行文字。

`Session unstable.`

林川动作停住。

他看了几秒。

不是系统常见报错。

至少他没见过这种写法。

“哪来的session……”

林川往上翻终端记录。

奇怪的是，之前执行过的命令全部消失了。

屏幕上只剩：

`[unknown@unknown /]$`

和那句：

`Session unstable.`

就在他准备开抓包工具的时候，终端又一次自动刷新。

这次出现了新的内容。

`Connection established.`

下面紧接着又跳出一行。

`Remote request detected.`

林川的手停在鼠标上。

远程请求？

谁？

他下意识看了一眼机房门。

玻璃门外是一条空荡荡的走廊。

感应灯已经熄灭，只能看到安全出口幽绿色的光。

身后几十台服务器仍然稳定运行。

风扇低沉地嗡鸣。

没有任何异常。

林川重新看向屏幕。

`Remote request detected.`

那行文字还在。

他敲下：

`ps`

这是他今晚第一次真正产生某种说不出的感觉。

不是害怕。

而是一种很强烈的违和感。

像是在一份熟悉得不能再熟悉的代码里，突然看见了一行完全不属于这个项目的东西。

终端刷新。

一张极其简陋的进程列表出现。

`PID    NAME`

`1      world`

林川没有动。

风扇声仿佛在这一瞬间变得格外清晰。

几秒后，他向后靠了一点。

“……world？”

他甚至笑了一下。

“谁写的破程序？”

PID为1的进程叫world。

如果这是某个同事写出来吓人的恶作剧，那多少是有点中二了。

林川试着查看更多内容。

没有反应。

再次执行`ps`。

仍然只有这一行。

`1      world`

没有systemd。

没有内核线程。

没有任何其他进程。

只有world。

林川忽然感觉屏幕亮度似乎变高了一些。

他眯了眯眼。

终端背景原本应该是纯黑色，可现在黑色深处像隐约浮动着一些极淡的线条。

那不是字符。

更像某种复杂到无法看清的图案。

密密麻麻。

一层覆盖着一层。

林川盯了几秒，眼睛开始发酸。

他移开视线。

“真出幻觉了？”

他已经连续加班好几天。

再加上今晚两杯咖啡，这时候看到点奇怪东西，好像也不是完全无法解释。

可就在下一秒。

屏幕突然跳动。

`Remote request accepted.`

林川猛地坐直。

“我什么时候accept了？”

他根本没操作。

紧接着，下一行出现。

`Target confirmed.`

林川脸上的表情慢慢消失。

这次他没有继续输入命令。

而是直接拔掉了电脑网线。

咔。

水晶头弹出。

电脑右下角的网络图标瞬间变成断开状态。

终端窗口却没有消失。

光标仍然在闪。

一下。

一下。

像是什么东西正在另一端等待。

林川的手缓缓从网线上移开。

机房里的温度似乎更低了。

他盯着屏幕。

过了两秒。

新的文字出现。

`Session unstable.`

随后是：

`Connection will be lost.`

林川沉默。

拔了网线，连接当然会丢。

这一点并不奇怪。

真正奇怪的是……

为什么这个终端还活着？

他尝试关闭窗口。

鼠标点击右上角。

没有反应。

Alt+F4。

没有反应。

任务管理器。

打不开。

甚至Windows桌面的任务栏都像被彻底冻住。

只有这个终端依然正常。

林川第一次产生了真正关机的念头。

他伸手按向主机电源键。

还没碰到。

屏幕突然刷出大量字符。

速度极快。

快到根本来不及看清。

一行接一行向上滚动。

林川只捕捉到了其中几个零散的词。

`request`

`coordinate`

`soul`

`permission`

还有一个不断重复出现的单词。

`anchor`

锚点？

林川脑海里刚闪过这个念头。

所有字符骤然停止。

屏幕重新恢复成一片黑色。

只剩最后两行。

`Anchor established.`

`Waiting for detach.`

林川呼吸停了一瞬。

机房里依然只有服务器风扇运行的声音。

他看着最后那个单词。

Detach。

分离？

卸载？

脱离？

他不知道为什么，突然觉得这个词用在这里有些不舒服。

就像它描述的不是某个连接。

而是某种更具体的东西。

林川尝试输入：

`clear`

无效。

又输入：

`reset`

没有结果。

他犹豫了一下。

最后还是敲下了那个最简单的命令。

`exit`

回车。

终端安静了。

一秒。

两秒。

三秒。

林川松了口气。

果然只是某个奇怪的程序。

他正准备强制重启电脑。

屏幕中央突然出现了一行字。

不是传统终端输出。

而是孤零零地悬在黑色背景中央。

`Detach current existence?`

下面出现：

`[Y/N]`

林川的手停住。

存在？

他重新读了一遍。

`Detach current existence?`

不是connection。

不是session。

是existence。

存在。

“谁英语这么烂……”

林川骂了一句。

可他的声音在安静的机房里显得异常突兀。

他忽然注意到一件事情。

服务器的风扇声变小了。

不。

不是变小。

是正在消失。

一台。

两台。

十台。

几十台。

原本充斥整个机房的轰鸣，像是有人正在一点一点把声音从现实中抽走。

林川猛地转头。

服务器还亮着。

指示灯依旧闪烁。

可他听不见了。

空调没有声音。

电脑没有声音。

甚至刚才手指摩擦桌面的声音也消失了。

整个世界突然陷入了一种绝对的寂静。

林川站了起来。

椅子向后滑动。

无声。

他低头看向自己的手。

然后僵住。

他的右手边缘正在变淡。

不是透明。

而像是失去了清晰的轮廓。

皮肤和空气之间出现了一层模糊的灰白色。

从指尖开始。

一点一点向手掌蔓延。

林川终于意识到事情可能比“服务器出了问题”稍微严重那么一点。

他立刻看回电脑。

屏幕上依然只有那个问题。

`Detach current existence?`

`[Y/N]`

光标停在后面。

等待输入。

“操。”

林川第一次感觉到心跳明显加快。

他试着输入N。

键盘没有反应。

再按。

还是没有。

屏幕上的光标继续闪动。

与此同时，他的左手也开始模糊。

视野边缘逐渐出现细碎的黑色。

他伸手去拔电脑电源。

手掌却直接穿过了机箱侧面。

林川整个人停住。

他慢慢低头。

自己的手已经看不见了一半。

没有疼痛。

没有知觉。

只是单纯地……

消失。

屏幕上的文字再次变化。

`Detach process has begun.`

`Confirmation required.`

林川死死盯着那两行字。

他突然明白了一件事。

刚才那个`exit`，可能真的执行了。

而现在需要的只是确认。

可问题是，他根本不知道确认之后会发生什么。

N不能输入。

只有一个选项。

或者说，从一开始就没有选项。

视野越来越暗。

身体也开始失去重量。

林川最后看了一眼周围。

机房。

服务器。

喝了一半的咖啡。

桌上还没吃完的面包。

还有屏幕角落显示的时间。

23:59:58。

23:59:59。

数字跳动。

00:00:00。

日期进入新的一天。

林川不知道自己为什么在这种时候还有心情想这些。

他只觉得有点荒谬。

加班加到零点。

然后疑似被Linux命令送走。

如果这也算工伤，他希望公司至少别赖账。

视野只剩最后一点光亮。

林川抬起已经快要消失的手。

食指落下。

Y。

回车。

刹那间。

所有光芒熄灭。

最后一行文字在黑暗中一闪而过。

`User detached.`

紧接着。

林川听见了声音。

不是服务器。

不是空调。

而是无数人同时吟诵某种陌生语言的声音。

宏大。

庄严。

又带着某种压抑不住的恐惧。

黑暗深处，有人突然大喊。

“坐标锁定！”

“继续！”

“不要让通道关闭！”

另一个苍老的声音几乎在咆哮：

“召唤已经完成了！”

“不对……”

“有什么东西过来了！”

林川睁开眼。

第一眼看到的，是一座足有十几米高的穹顶。

第二眼，是漫天燃烧的蓝色火焰。

第三眼。

是一群穿着长袍、面色惨白的人。

所有人都在看着他。

而他正站在一个巨大的银色法阵中央。

法阵之外。

一个白发老人死死盯着他的眼睛。

嘴唇微微颤抖。

“你……”

“到底是什么东西？”

林川没有回答。

因为就在这一瞬间。

他的视野最下方。

一行只有他能够看见的文字，悄无声息地浮现出来。

`Session established.`

【第一章 完】
