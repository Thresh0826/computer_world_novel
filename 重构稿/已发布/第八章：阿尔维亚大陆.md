# 第八章：阿尔维亚大陆

林川没再回头。

那道落在背上的视线让他有些不舒服，但图书馆里这么安静，他总不能因为一个白头发老人看了自己几眼就转身逃跑。

林川今天只想查清三件事：自己在哪里，这个社会怎么活下去，还有这里的魔法到底怎么运作。

他先找到一本《诺维斯地理概览》。地图画得很粗，许多地方连名字都没有，但至少给了他一个位置。

这个世界叫诺维斯。他所在的地方是阿尔维亚大陆上的维尔兰王国，贝恩只是王国东部的一座小镇。

贝恩再往东就是洛恩。那座城市位于河流入海口，海运、河运和商路在那里交汇，规模远不是贝恩能比。阿尔文商队常驻洛恩，也就不奇怪了。

林川用手指沿着贝恩到洛恩的路线慢慢划了一遍。莫里斯留下的名片在那里才真正有用；如果想找更多资料和回去的线索，大城市显然也比贝恩合适。

地图边缘还标着大片陌生土地和国家，林川没有继续细看。他连维尔兰都没弄明白，现在研究那些地方没有用。

第一个问题，勉强有了答案。

他又翻了货币和职业相关的基础读物。十枚铜币换一枚银币，十枚银币换一枚金币。林川摸了摸只剩十四枚银币的钱袋，这点钱撑不了多久。

这个社会有很多职业，战士、法师和其他高风险职业都有阶位。护卫、猎人以及不少正式工作，都会查看阶位证明。林川现在既没有正式职业，也没有能证明身份的东西，身上的剑和皮甲只能让他看起来不像流民。

想靠十四枚银币慢慢找回家的办法不现实。他得先找到一份能挣钱的事，再想办法补上职业身份。

翻书时，他偶尔还能感觉到大厅尽头那道视线。白发老人没有离开，他也没有回头确认。

直到下午，林川才找到一本《基础魔法教学》。

书的开头只讲了两件事。

第一，施展魔法需要理解作用对象和运转原理。第二，施法者必须拥有能够驱动魔法的能量。

林川在第一条上停了很久。

他的调用和本地法师学习魔法，似乎存在某种相似之处：他至少得理解自己想让什么东西发生，正确的调用才可能出现。

`fire()`和`dash()`出现时，他都有明确的目标：点燃木柴，或者让自己加速。但知道想要什么结果，不等于理解魔法怎样完成。

可相似也只到这里。他的调用显然绕过了普通法师大量学习和构造魔法的过程。为什么能绕过，他不知道。

`hardening()`和`strengthen()`更能说明问题。他已经可以调用这两个能力，却说不清皮肤为什么变硬，力量又是怎样增强的。

能够调用，不等于真正理解。

林川继续往后翻。书里提到魔法结构，却没有在基础章节展开；至于能量，他体内现在确实有一股，但从哪里来、和别人是否一样，也没有答案。

他暂时只能确定，魔法不是念出名字就会发生。里面至少涉及理解、结构和能量。

仅此而已。

“行吧。”

林川合上书。

“还是得先挣钱。”

窗外的光一点点暗下去。

等他反应过来，图书馆里已经亮起了几盏灯。管理员换过一次班，原本就不多的读者也走了大半。

林川把看过的书放回原处，揉了揉有些发酸的眼睛。

一整天就这么过去了。

他起身准备出去找东西吃，经过大厅尽头时，脚步又慢了下来。

那个白发老人还在。

老人身边的书比白天更多，侍从站在旁边，正低声和他说着什么。林川听不清内容，只在转身时，听见老人压得很低的几个词。

“界蚀……”

“他……”

林川脚步一顿。

白发老人已经抬起头，目光落在他身上。

这一次，林川没再笑。
