林川回到旅店，把门关上，又顺手插好门闩。

直到房间里只剩下他一个人，胸口那阵急促的跳动仍然没有停下。

塞维尔从头到尾都很和蔼，既没有威胁他，也没有阻止他离开。可林川站在那人面前时，始终有种说不出的压迫感。

尤其是在密室里。

对方明明只是个白发老人，林川却觉得，只要自己哪句话说错了，下一秒就可能变成一地人类碎片。

他现在甚至不知道能处理界蚀水平的法师意味着什么，只知道自己绝对打不过。

林川在房间里来回走了几圈，强迫自己把呼吸放慢。等心跳终于不再撞得胸口发疼，他拉开椅子坐下，把塞维尔给的卡片放到桌上。

这段时间，他好像一直在被事情推着走。

穿越，逃命，打狼，跟着商队进贝恩。刚有地方住，又去图书馆、猎行会，紧接着便和凯恩他们出发讨伐裂甲兽。

除了打架就是学习。

再不然就是睡觉、吃饭，想办法让自己别饿死。

他甚至没有认真想过以后怎么办。

林川看着桌上的卡片，开始整理目前能够确定的事。

他想回去。

这是最重要的目标。

可要找到回去的方法，就绕不开界蚀。自己来到诺维斯时身处界蚀，`quit()`也正是在那里生效。塞维尔还从他身上感觉到了特殊的界蚀气息。

这些事情未必存在直接关系，却已经是他手里最接近答案的线索。

问题是，他没有资格接触更高层的资料。

洛恩图书馆的第二层需要更高阶的职业证明，第三层更是要特殊令牌。想光明正大地进去，最稳妥的办法就是提升阶位，积累身份，再接触更高级的图书馆和界蚀记录。

林川在地球时就习惯做长期准备。

有些事情一两个月看不到结果，那就做一年。只要方向没错，慢一点也比胡乱撞上去强。

他给自己定了一个暂时的目标。

两年。

尽量在两年内，拿到查阅最高层资料的资格。

至于怎么提升阶位，怎么获得那些令牌，他现在一个都不知道。

“想得挺美。”

林川靠回椅背，自嘲了一句。

能不能活两年都不好说。

窗外已经彻底暗了下来。林川今天先去见了凯恩，又在图书馆看了半天书，最后还被塞维尔带进密室盘问，脑子早就累了。

“不管了，先睡觉。”

他把卡片压到桌角，又确认裂甲兽核心和通讯石都在袋子里，才脱掉外衣躺到床上。

这一觉，是林川来到诺维斯以后睡得最安稳的一次。

没有带伤赶路，没有魔兽在附近刨土，也不用守着火堆担心半夜被野兽拖走。

可他还是做梦了。

梦里，林川回到了自己的工位。

办公室的灯亮着，周围却一个人都没有。窗外一片漆黑，连对面大楼的灯都看不见。

他坐在电脑前，屏幕里开着一份写到一半的Python代码。

有个功能怎么都跑不起来。

林川检查半天，才发现缺了一个库。代码是从网上抄来的，说明写得乱七八糟，也没标依赖版本。

他懒得继续翻。

先装了再说。

`pip install`

命令敲下，进度停在原地。

失败。

林川又试了一次。

还是失败。

终端明明弹出了错误信息，那些字却糊成了一片。无论他怎么凑近，都看不清报错究竟写了什么。

“不是，你倒是告诉我缺什么啊。”

他换了几个版本，重新连接软件源，又把命令删了重打。

没有一次成功。

林川烦得开始敲桌子。就在这时，屏幕突然黑了。

代码、终端、报错，全没了。

漆黑的屏幕中央浮出一行白字。

`connection established`

林川盯着它看了几秒，身体猛地僵住。

他依旧没有意识到自己在做梦，只记得上次看到这行字以后发生了什么。

“卧槽。”

林川推开椅子往后退。

“我不过去！”

屏幕上的白字开始一遍遍刷新。

`connection established`

`connection established`

`connection established`

办公室的灯同时熄灭。

林川退到墙边，周围的黑暗却像活了一样向他压过来。他拼命去拉身后的门，门把怎么都拧不动。

“别拉我过去！”

屏幕上的白光越来越亮。

“不要！”

“不要啊！”

林川猛地从床上坐了起来。

胸口剧烈起伏，睡衣已经被冷汗浸湿。他下意识抓住床沿，过了好一会儿，才认出眼前是旅店的房间。

窗外已经亮了。

“卧槽，又是这个梦。”

他抹了把脸，靠在床头喘气。

来到诺维斯以后，他对时间越来越没概念。天黑就睡，天亮就醒。没有闹钟，没有通勤，也不用计算今天是早十晚十还是加班到半夜。

放在以前，这种作息简直健康得不像程序员。

问题是睡得再早，也架不住做这种梦。

林川坐了一会儿，突然想起一件事。

核心。

银背狼核心就是在那场古怪的梦后消失的。

他掀开被子下床，几步走到桌边，抓起昨天带回来的布袋。

裂甲兽核心还在。

暗色的骨壳贴着掌心，里面的土黄色微光也没有变化。

林川松了口气。

两百枚银币还没凭空蒸发。

不过梦里那条始终失败的安装命令，却怎么也忘不掉。

`pip install`

林川低头看向手里的核心。

上一次，银背狼核心只能在接触时提供`hardening()`和`strengthen()`。梦醒以后核心消失，两项调用却留在了他体内。

像是外部的东西被装了进来。

这个念头一出现，林川便有些坐不住了。

他将核心放到桌上，手指按住外层骨壳。

`ls`

这一次，出现的不是单纯的“裂甲兽核心”。

`裂甲兽核心-1`

林川盯着最后那个数字。

版本号？

还是别的标记？

他暂时看不明白。可梦里的那条命令已经变得异常清晰，像是在等他把核心的名字填进去。

林川犹豫片刻。

先试试。

`pip install 裂甲兽核心-1`

命令开始执行。

“卧槽。”

一条半透明的进度出现在视线里，从零开始缓慢向前移动。

“这他妈也行？”

林川连眼睛都不敢眨，眼看进度一点点推进。十、二十、三十，走到接近九十时，进度突然停住。

安装失败。

这次错误信息没有消失。

林川意念一动，那片原本模糊的内容迅速变得清楚。

空间不足。

完整安装所需空间：90%。

当前可用空间：80%。

下面还列出了四项内容。

岩甲：15%。

地感：20%。

震步：20%。

瞬脊刺：35%。

林川看着这份报错，半天没动。

“还有存储概念？”

他脑子里装的东西，难道真会占空间？

既然有已用和可用，那应该就能查看。

`df -h`

一份极其简略的结果出现在意识里。

精神存储。

总量：100%。

已用：20%。

可用：80%。

林川盯着“精神存储”四个字。

这显然不是真有一块硬盘塞在他脑子里，只是那部分无法理解的东西，再次变成了他熟悉的形式。

至于已经占用的百分之二十，究竟包括什么，暂时看不出来。

完整安装裂甲兽核心需要百分之九十。

差了百分之十。

“还得选装。”

林川重新看向那四项能力。

岩甲和他已经拥有的`hardening()`有些重合。震步看起来与移动有关，他现在也有`dash()`。

真正缺少的，是感知和远距离攻击。

裂甲兽那晚藏在地下时，他们几乎看不到它的位置。如果能使用地感，至少不会等到脚下炸开才发现危险。

瞬脊刺更不用说。

那根骨刺差点当场杀死凯恩。

林川很快做出决定。

岩甲和震步暂时舍弃。

先装地感和瞬脊刺。

`pip install 裂甲兽核心-1.地感`

进度条再次出现。

这一次顺利走到了尽头。

安装成功。

一股沉重的能量从核心涌入手臂，随后散向全身。林川闭上眼缓了片刻，直到那股发胀的感觉减轻，才开始第二次安装。

`pip install 裂甲兽核心-1.瞬脊刺`

进度比刚才慢得多。

林川等了好一阵，最后一小段才终于填满。

安装成功。

裂甲兽核心仍然留在桌上，没有像银背狼核心一样消失。只是里面的土黄色微光暗淡了许多，外层骨壳也失去了先前那种沉重的魔力感。

林川再次执行`df -h`。

精神存储。

已用：75%。

可用：25%。

数字完全对得上。

两项新的调用也随之浮现在脑中。

`earth_sense()`

`spine_shot()`

林川没有马上尝试地感，而是先看向瞬脊刺。

这个能力给出的信息比之前的函数更多一些。

投射物。

方向。

目标。

裂甲兽使用的是自己的骨刺，但投射物似乎不一定非得是骨头。

林川从桌上拿起一支木笔。

笔不长，尾端还有一小块被他咬出来的浅痕。他把椅子拖到墙边，又将被子折了几层，垫在椅背后面。

真打穿了，至少不至于射到隔壁房间。

林川站到几步外，用两根手指捏住木笔，将目标锁定在椅背中央。

`spine_shot(木笔，椅背)`

没有蓄力。

也没有任何预兆。

啪！

木笔瞬间从指间消失。

椅背猛地一震，折好的被子向后鼓起。林川走过去拉开被子，那支木笔已经扎进木板，只剩短短一截尾端露在外面。

整个过程快得几乎看不清。

林川伸手碰了碰笔尾，没能拔出来。

“瞬发？”

裂甲兽当时还需要蓄能。

到了他这里，只要指定投射物和目标，攻击便直接完成了。

林川还没来得及继续检查，桌上的蓝色通讯石忽然亮了起来。
