# 第36—37章与澜河空船事件评估

评估日期：2026-09-18。

评估对象：重构稿第36章《离开洛恩》、第37章《初入澜河》，以及尚未进入正文的“澜河空船事件”最新框架。

## 总体结论

第36—37章顺利完成了洛恩暗杀高潮后的降速、秘密交换与场景迁移，人物关系推进比情节推进更突出。两章的完成度合格偏上，其中第37章的对话和关系变化明显强于章末城市说明。当前空船事件的因果闭环已经能够支撑一个中型篇章，综合潜力高于此前单纯的空船解谜或临时黑环追杀方案，但执行难度也明显提高。

综合评价：

* 第36章：7.7/10。
* 第37章：8.1/10。
* 第36—37章作为过渡组合：8.0/10。
* 空船事件当前框架：8.6/10；若信息投放失控或Java修复缺乏前置失败，实际成稿可能跌至7分左右。

## 第36章《离开洛恩》

### 有效之处

1. 梦境承担了暗杀余波。地球工位、Bug工单、黑暗箭、`Welcome.`和菲利克斯状态字段被压进同一个梦，能够同时表现林川的地球记忆、死亡刺激与认知接口焦虑，不是单纯为了制造惊吓。
2. 菲利克斯的状态变化提供了可验证的新信息。“恢复速度：极快”降为“中等”，比直接解释复活机制更克制，也让`ls`新增固定字段成为后续可持续观察的现象。
3. 凯恩承担了必要的信息补链。西奥被困、空间控制松动、外部发现异常和不足十分钟的救援过程得到人物视角内的解释，弥补了第35章援军突然出现的问题。
4. 迁居选择与林川目标一致。林川没有被三百枚银币直接吸引，而是优先考虑界蚀调查和返回洛恩的距离，符合他此前的长期计划。
5. 凯恩晋升三阶放在离别前有效。它既给洛恩阶段留下一个正向结果，也避免整章只有伤亡、驱离和告别。

### 主要问题

1. 洛恩官方终止保护的制度边界还不够清楚。阿尔文商队承担预算、城防军提供人员、官方又能决定迁居，三方责任容易混在一起。后文若再次提及，应明确这是“终止特殊保护并提供自愿迁居补贴”，而不是城市可以随意驱逐受害者。
2. 五十与三百枚银币的补贴差距很大。按照此前任务报酬体感，三百枚已经是足以显著改变角色财务状态的金额。需要让读者理解远途成本、风险和洛恩希望二人远离的程度，否则容易显得官方为了推动剧情突然撒钱。
3. 洛恩告别略快。格兰特、西奥、莫里斯和塞维尔都没有直接出现，情感上会有轻微的“事件结束后立刻清场”感。未必需要补一整章告别，但后续可通过通讯石、信件或林川回想保留联系，避免洛恩人物集体失去存在感。
4. 梦境篇幅相对较长，后半章又承担救援解释和迁居通知，功能较多。单章不算失衡，但发布时应观察读者是否觉得高潮之后连续解释过密。

## 第37章《初入澜河》

### 有效之处

1. 秘密交换建立在此前事件上。林川亲自检查过心跳，菲利克斯亲眼看见四倍强化，双方都有无法再装作没看见的事实，因此谈话不是作者强行安排的设定说明。
2. 对话有明确的人物差异。林川要求事实、不断追问边界；菲利克斯先胡扯药物，再用玩笑缓冲，最后才透露有限信息。二人的互动比单纯互报能力更自然。
3. 双向保密推进了关系。林川没有得到完整答案，菲利克斯也没有知道计算机式机制，信任增加但信息边界仍在，适合长期搭档关系。
4. 澜河城初景具有辨识度。分流水道、桥梁、码头、控风转向和魔法装卸共同构成城市功能，不只是把洛恩的建筑换成水景。
5. 三日车程同时承担养伤和空间转换，节奏干净，没有把普通赶路拆成多个缺乏事件的章节。

### 主要问题

1. “任何伤害都不会真正要我的命”过于绝对。如果后续没有代价、次数、恢复材料或特殊例外，菲利克斯的战斗风险会迅速消失。当前资料已将其限定为菲利克斯自我认知，正文也应保留这种不可靠性。
2. 北境战法家族的信息集中度偏高。冰魔法、狂战士、本人无魔力、离开北境和不死恢复在一次谈话中全部出现，虽然对话消化了部分负担，仍需要后续通过行为或人物再验证，而不是把这段话当成最终人物档案。
3. “弗雷尔卓德”联想符合穿越者口吻，但会强化游戏梗感，也可能随时间降低文本耐久度。若全书一直保留现代作品联想，可以使用；若整体追求严肃异世界氛围，应控制频率。
4. 章末城市描写以全景介绍为主，缺少一个属于澜河的具体人物动作或小冲突。下一章最好立刻让两人遇到住宿、登记、码头工作或航运规则，避免城市只停留在风景层面。

## 空船事件框架

### 当前最强的部分

1. 核心谜团已经形成闭环。原B节点被界蚀覆盖、B2绕行、无人测试航道未注销、主路线偶发失联、备用路线送船进入影港、自动回收只登记船体，这条因果链能够解释“船回来、人不见了”，不依赖单纯诅咒或角色集体犯蠢。
2. 影港漏洞与Java式能力高度一致。问题不是修改一个数值，而是船只、路线、节点和乘员之间缺少完整对象关系；林川必须组织完整运输对象、建立新路线、测试、迁移和关闭旧结构。它确实需要比Python式参数调用更高一层的认知。
3. 两次秘密登船各有功能。第一次失败用于观察正常结构、建立人物分歧和找到异常窗口；第二次才因高强度校验、林川界蚀气息和界蚀鲨攻击触发旧航道。只要第一次篇幅受控，就不会成为纯重复。
4. 护航队长冲突有充分立场。他面对偷渡者、引航结构接触者、受损船只和看似正常的港口，命令船员下船属于尽责；林川阻止下船也属于救人。双方战斗来自信息差和倒计时，不依赖反派降智。
5. 三场战斗区分明确。首次鲨战求生、队长战争夺决定权、最终鲨战保护修复，目标和胜负条件不同，能够缓解连续怪物战的疲劳。
6. 黑环长刺暂时退场是正确决定。澜河事件已经有航运体系、女角色、护航队长、界蚀鲨、影港和Java入门，再叠加黑环追杀会破坏焦点。

### 最大风险

1. 信息量过高。A、B、B2、C、测试C'、主路线、备用路线、自动回收和完整运输对象若在一两章中集中解释，会像技术文档。正文必须按照“现象—局部判断—错误假设—新证据—完整真相”分批释放。
2. 林川气息吸引界蚀鲨容易变成主角便利。必须继续保留“此前船只也会随机失踪；林川只是在特殊校验窗口把低概率变成高概率”这一点，不能写成所有历史事件都在等待林川出现。
3. 女角色A目前仍是功能集合。她拥有旧资料、支持第二次调查、稳定术式并连接死去法师，但姓名、职业、欲望、缺点和错误判断都未确定。若只负责提供资料和认可林川，她会迅速工具人化。
4. 第一次登船可能拖慢节奏。它必须得到三项明确成果：确认备用路线存在、发现特殊校验窗口、制造菲利克斯与林川的分歧。若只写“什么也没发生”，应压缩处理。
5. Java修复存在机械降神风险。林川需要经历误读、失败测试或资源不足，最后依靠此前逐步理解完成迁移；不能看到完整结构后立即写出正确方案。修复也必须付出明确成本。
6. 幸存者生存条件尚未解决。三个月尺度下需要确定影港主观时间、食物、水、疾病与人数，否则“几十人一直在港口等船”会产生新的漏洞。
7. 护航队长开战前的信息交换必须受倒计时限制。如果时间充足，双方仍然不解释就动手，会显得人为。船体漏水、伤员、假港接引和自动回收倒计时应共同压缩决策时间。
8. 最终界蚀鲨不能被Java一键删除，也不能只靠高倍率瞬脊刺秒杀。更合适的是利用航道、诱饵船、狭窄水域、锁链和团队配合制造击杀条件，由林川完成关键一击。

## 开始正文前最需要锁定的事项

1. 女角色A的核心欲望与一个会造成实际后果的缺点，而不仅是身份。
2. 首次空船回港时，林川为什么恰好在港口，以及他在港口已经生活了多久。
3. 两次登船使用的船型、船员数、护航者人数和异常校验窗口。
4. 影港的主观时间、幸存人数、食物与饮水来源。
5. Java入门至少一次失败及明确代价。
6. 最终战的空间布置和界蚀鲨击杀方式。

## 公平结论

第36—37章不是强爆点章节，优点在于关系推进和自然换地图，缺点在于制度解释、设定集中与章末缺少即时钩子。它们作为高潮后的过渡是合格且稳健的，但单独拿出来并不具备很强的追读爆发力。

空船事件则相反：概念、因果和视觉潜力都很强，已经是目前第二卷较有辨识度的篇章方案；但它并不天然好写。真正决定成败的不是节点拓扑是否严密，而是女角色A能否成为人物、技术真相能否分层揭示、三场战斗能否改变关系，以及Java修复是否经过失败和代价。如果这些部分落实，事件有能力成为当前全书第一个同时完成世界观、能力进阶、人物关系和主线回归的完整中篇；如果只把大纲逐条翻译成正文，则会显得复杂但缺乏情感。
