# 第十章：裂甲兽

凯恩盯着林川那块新得发亮的工牌，沉默了两秒。

“裂甲兽。”

他把任务单递过来，指着上面的名称。

“一个食草魔兽，平时性子不算差。吃草、挖洞，遇见人也不会主动追着咬。可最近不知道怎么回事，老往人住的地方钻，把村子周边闹得一塌糊涂。”

林川接过任务单，低头看了一眼。

上面的字他能认个大概，下面确实写着一段前情提要。目标活动在洛恩附近，已经毁了几处田地和围栏，还有村民的屋墙被从地下顶裂。

他抬头看凯恩。

“你怎么知道的？”

凯恩愣了一下。

“讨伐单上写着。”

林川又低头看了眼任务单。

还真写着。

“……”

行。

他还以为这人有什么特别渠道，结果是自己看公告没看全。

凯恩看他不说话，继续道：“接吧。你不需要上去跟裂甲兽拼命，跟着队伍就行。路上食宿我们包了，任务结束再给你十枚银币。”

十枚银币。

林川在心里过了一遍。

钱不算多，可对他现在来说，够住一阵客栈，够吃不少顿饭。更重要的是，食宿全包。

这意味着要出远门。

柜台后的女人听见这话，直接笑出了声。

“凯恩，你这家伙真会算账。一单两百银币的讨伐，你就给人家十枚？”

凯恩回头看她。

“他不用主战。”

“那也不能十枚。”

女人朝林川招了招手，“小伙子，别让他一句食宿全包就骗过去。裂甲兽是三阶，你要真跟着去，路上遇到点别的东西，也不是坐着看戏。”

凯恩皱了皱眉。

“二十。”

“我没说要加到二十。”

“那你闭嘴。”

柜台附近的人都笑了。

林川没跟着笑。他抓住了刚才最关心的那句话。

“我们要去哪？”

“洛恩。”凯恩说，“裂甲兽在洛恩附近的村庄捣乱。那边最近也有界蚀的麻烦，能调的人大多被叫去处理界蚀了，这种讨伐就落到我们头上。”

界蚀。

林川的手指微微一紧。

刚从图书馆出来，白发老人压低声音说出的两个字还在他脑子里打转。现在凯恩又提起界蚀，而且目的地还是洛恩。

洛恩有更大的城市，有法师协会，有阿尔文商队留下的名片。

现在还多了一件和界蚀有关的事。

这趟路本来就值得走。

林川看了一眼凯恩身后的三人。盾卫、弓箭手、法师，再加上凯恩这个战士，至少配置看起来比他一个人走荒野靠谱得多。

当然，三阶魔兽听起来也不太像能随便碰的东西。

他问：“如果打不过，我直接跑，行不行？”

凯恩先是一愣，随后笑了。

“你不跑，我们也得跑。”

巴洛在后面接了一句：“跑快点，别挡路就行。”

“那我接。”

林川把任务单递回去。

凯恩朝柜台抬了抬下巴。

“走，按手印。”

猎行会的登记比他想得正式。工作人员重新翻出任务册，把林川的名字补进队伍名单，又让五个人依次在纸上按下手印。

凯恩。

巴洛。

米娅。

西蒙。

林川。

任务报酬两百银币，五人队伍，裂甲兽讨伐。

林川看着那行字，忽然有种刚被拉进陌生项目组的感觉。人员齐了，工单也开了，明天开始出差。

区别只是这次要处理的，不是什么线上故障。

是三阶魔兽。

办完登记，凯恩把任务单收好。

“回去休息。明天早上十点，贝恩东门见。”

林川点头。

“行。”

离开猎行会后，他慢慢往客栈走。

街上人已经少了，店铺也陆续关门。林川摸了摸腰侧短剑，又想起凯恩说的裂甲兽。

食草。

温和。

三阶。

这几个词放在一起，总让人觉得不太对。

二阶队伍去讨伐三阶魔兽，猎行会还要求至少五个人。凯恩嘴上说得轻松，显然没打算真让他坐在旁边看热闹。

回到客栈，林川躺到床上，却怎么都睡不着。

他翻了个身，又坐起来。

裂甲兽到底长什么样，靠什么攻击，有没有魔法，凯恩说得太笼统。明天就要跟着去，总不能到了地方才发现自己连目标都认不出来。

林川穿回外衣，重新出了门。

图书馆居然还亮着灯。

他本来以为这种地方天黑就该关门，没想到门口的管理员只是换了个人。夜班管理员坐在桌后，困得直打哈欠，见林川进来，只抬眼确认了一下，便继续低头看自己的册子。

异世界图书馆，居然还是全天开门。

林川没耽误，直奔魔兽分类的书架。

一排排厚册子上落着灰，里面不少书连边角都卷了。他翻找了一阵，终于抽出一本《维尔兰东部常见魔兽目录》。

裂甲兽。

三阶魔兽。

图上的东西比林川预想中大得多，身体低矮粗壮，像一头披着石甲的大蜥兽。背部和头部覆盖着一层层天然甲片，前肢粗得离谱，爪子很适合刨土。

食草，通常活动在开阔地和松软土层附近。

性情温和，非受惊或领地被侵入时，一般不会主动攻击人类。

林川看到这里，嘴角抽了一下。

怪不得凯恩说得那么轻松。

可再往下翻，语气就没那么温和了。

裂甲兽冲撞时速度极快，甲层能抵挡大部分普通攻击。它们还会短距离钻入地下，借地形躲避攻击或突然突进。

书页最下方还有一行加粗的小字。

极少数变异个体会在背甲间生成可脱离的骨刺，近距离蓄能后射出，称为“瞬脊刺”。

林川停住了。

瞬脊刺的威力极强。三阶以下的职业者，若被正面命中要害，通常没有活下来的机会。

“又食草，又温和。”

林川盯着那几行字。

“难怪二阶也敢去打。”

只要别撞上最倒霉的那种变异体，凯恩他们四个二阶，确实有机会解决一头普通裂甲兽。

可万一撞上了呢？

林川把书合上，又在原地站了一会儿。

明天要去洛恩。

有钱拿，有人带路，还能离界蚀更近一步。

这机会不能因为怕死就放掉。

但该做的准备，也不能省。

他回到客栈时已经很晚。

房间里安静下来，林川先把门锁好，拿起桌上的木杯。

`hardening()`

淡灰色从右手手背浮出来。

他伸指节敲了敲桌沿，声音比前几次沉了一些。林川没有维持太久，散去调用，等那股发闷的疲惫缓过去，才又握住木杯。

`strengthen()`

力量沿着手臂往上走。

木杯在掌心变得很轻。

这次他没有像白天那样立刻停掉，而是仔细感受那股力量从哪里开始，怎么附到手臂上，又在精神消耗变重前主动断开。

一次。

两次。

第三次时，他终于摸到了一点规律。

不是变得更强了。

只是比最开始少了点手忙脚乱。

但这也够了。

林川洗漱完躺回床上，临睡前把短剑放到触手可及的位置。窗外偶尔有车轮声经过，后来连声音也没了。

这一夜，他睡得很沉。

第二天醒来时，天已经亮透。

林川下楼吃了顿早饭，又检查了一遍皮甲绑带、短剑和钱袋。等时间差不多，便往贝恩镇东门走去。

城门外，凯恩四人已经到了。

巴洛背着塔盾，米娅检查箭壶，西蒙站在一旁，法杖靠着肩。凯恩见林川过来，抬手打了个招呼。

“人齐了。”

林川走到队伍里。

五个人离开贝恩镇，沿着向东的道路出发。
